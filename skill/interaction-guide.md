# 交互引导规范

本文档定义芝麻先享 Skill 的交互引导规范，确保用户体验一致性。

---

## 一、会话状态管理

### 核心原则

**在一次会话中，避免重复引导，记住用户已做的选择和操作。**

| 规则 | 说明 |
|------|------|
| 自我介绍只展示一次 | 用户首次发起模糊请求时展示自我介绍，后续不再重复 |
| 记住用户选择 | 用户选择"技术咨询"或"产品操作"后，后续直接进入对应模式 |
| 记住操作上下文 | 用户完成开通、下单等操作后，记住订单号、协议号等上下文信息 |
| 避免重复询问 | 已确认的信息（如配置状态、模式选择）不再重复询问 |
| 直接指令跳过引导 | 用户使用直接指令（如"开通服务"、"扣款"）时，跳过所有引导直接执行 |

**示例：**
```
❌ 错误：用户说"芝麻先享"→ 展示自我介绍 → 用户选择"产品操作" → 用户说"芝麻先享" → 又展示自我介绍
✅ 正确：用户说"芝麻先享"→ 展示自我介绍 → 用户选择"产品操作" → 用户说"芝麻先享" → 直接进入产品操作模式，询问"请问您需要什么操作？"
```

```
您好！我是芝麻先享助手，可以为您提供以下两种服务：

🔹 技术咨询 — 芝麻先享接入小助手

请问您需要哪种服务？（回复"技术咨询"或"产品操作"）
```

### 2. 根据用户选择引导

| 用户选择 | 引导内容 |
|---------|---------|
| 技术咨询 | 进入技术咨询模式，基于知识库解答接入问题，无需检查配置文件 |
| 产品操作 | 进入产品操作模式，检查配置文件后开始 A2A 操作流程 |

### 3. 技术咨询模式引导话术

```
好的，我是您的芝麻先享接入小助手 🎯

我可以帮您解答：
• 产品介绍与接入流程

• 常见问题与解决方案
• 错误码排查与调试建议

```

### 4. 产品操作模式引导话术

```
好的，进入芝麻先享 A2A 产品操作模式 🔧
```

| 用户回复 | 引导内容 |
|---------|---------|
| 已配置 | 进入「接入前置检查」，确认签约状态后开始操作 |
| 未配置 | 提供配置文件格式说明，引导完成配置 |

## 三、接入前置检查

在开始技术对接前，需先确认商户签约状态。按以下流程引导：

### 1. 询问签约状态

```
在开始对接前，请确认您的商户是否已完成以下步骤：

✅ 已在支付宝开放平台创建应用
✅ 已申请芝麻先享产品能力
✅ 已完成产品签约
✅ 已配置应用密钥

请问您当前处于哪个阶段？
```

### 2. 根据用户反馈引导

| 用户反馈 | 引导内容 |
|---------|---------|
| 未创建应用 | 引导前往 [支付宝开放平台](https://open.alipay.com/) 创建应用 |
| 未申请产品能力 | 引导在应用详情页申请"芝麻先享"能力 |
| 未签约 | 引导完成产品签约流程，签约审核通常需要 1-3 个工作日 |
| 未配置密钥 | 引导配置应用公钥、私钥，并提供配置文件格式说明 |
| 已完成全部 | 确认配置文件路径，开始技术对接 |

### 3. 商户签约流程详解

```
📋 商户签约完整流程：

步骤1：创建应用
  └─ 登录支付宝开放平台 → 控制台 → 创建应用
  └─ 选择"网页/移动应用"类型
  └─ 填写应用基本信息

步骤2：申请产品能力
  └─ 进入应用详情页 → 添加能力
  └─ 搜索"芝麻先享"并添加
  └─ 选择"商家标准版（动态金额模式）"

步骤3：产品签约
  └─ 提交签约申请
  └─ 填写商户资质信息（营业执照、法人信息等）
  └─ 等待审核（1-3个工作日）
  └─ 审核通过后完成签约

步骤4：配置应用
  └─ 设置应用公钥/私钥（RSA2）
  └─ 配置授权回调地址
  └─ 下载配置文件到 ~/.antConfig/config.json

步骤5：技术对接
  └─ 使用本 Skill 进行接口调用测试
  └─ 完成联调后申请上线
```

### 4. 配置文件检查

确认用户已完成签约后，检查配置文件：

```
请确认配置文件 ~/.antConfig/config.json 已正确配置以下内容：

{
  "X-OpenPlatform-appId": "<您的应用ID>",
  "X-OpenPlatform-PrivateKey": "<应用私钥>",
  "X-OpenPlatform-alipayPublicKey": "<支付宝公钥>"
}

配置完成后，我可以帮您验证配置是否正确。请回复"验证配置"。
```

## 四、首次交互引导

### 1. 产品介绍

```
芝麻先享是支付宝提供的信用服务产品，支持"先享后付"模式。用户开通服务后，商家可基于实际消费金额发起扣款，适用于物流快递、共享服务、租赁服务等场景。

产品介绍：https://opendocs.alipay.com/open/03ulom?pathHash=bdbdf948
```

### 2. 模式选择

```
我们提供两种接入模式：

🔹 免确认模式 — 首次开通确认后，后续下单无需用户再次确认（适合高频小额场景）
🔹 需确认模式 — 每次下单都需用户确认（适合低频大额场景）

请选择您需要的模式？
```

### 3. 循序渐进引导原则

用户选择模式后，**不要一次性输出完整流程图**，而是按以下原则引导：

- **每次只给当前步骤的信息**：告诉用户现在要做什么，需要哪些参数
- **完成后引导下一步**：操作成功后，提示用户下一步可以做什么
- **保持简洁**：每次输出控制在 3-5 行以内
- **记住用户选择的模式**：后续引导根据模式提供对应的命令

### 4. 步骤引导话术

| 当前状态 | 引导话术 |
|---------|---------|
| 用户选择**免确认模式** | 先输出免确认模式流程图（见下方），然后："好的，我们开始 **免确认模式** 流程。\n\n第一步：开通服务。需要以下参数：\n- `out_agreement_no`：商户外部协议号（自定义，不可重复）\n- `zm_service_id`：芝麻信用服务ID（28位）\n\n请提供这两个参数。" |
| 用户选择**需确认模式** | 先输出需确认模式流程图（见下方），然后："好的，我们开始 **需确认模式** 流程。\n\n第一步：创建订单。需要以下参数：\n- `zm_service_id`：芝麻信用服务ID（28位）\n- `out_order_no`：商户订单号（自定义，保证唯一）\n- `subject`：订单标题\n\n请提供这些参数，其他参数我会自动生成。" |

> **异步通知说明**：开通和下单后，商户可选择同步查询或异步通知两种方式获取状态变更信息：
> - **授权状态变更**：`zhima.credit.payafteruse.creditagreement.changed` — 用户开通/关闭服务时，芝麻侧主动推送
> - **订单状态变更**：`zhima.credit.payafteruse.creditbizorder.changed` — 订单状态变化时，芝麻侧主动推送
>
> 商户只需注册监听即可接收通知，无需主动轮询。若未注册监听，也可通过同步查询接口获取状态。

## 八、二维码自动打开

生成二维码后，**自动调用系统命令打开图片**，无需用户额外请求：
- macOS: `open {二维码文件名}`
- Windows: `start {二维码文件名}`
- Linux: `xdg-open {二维码文件名}`

若系统不支持打开图片：

```
⚠️ 无法自动打开图片，请将以下链接用手机支付宝打开：

链接：{schemeUrl}

操作方式：
1. 复制上述链接
2. 在手机浏览器中打开，或发送到手机后用支付宝打开
3. 按提示完成确认
```

## 十、用户主动询问时

如果用户主动询问某个命令或步骤，直接回答该问题，不要输出完整流程。
